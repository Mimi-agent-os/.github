# Contributing

## Issues

Bugs and ideas go in the affected repo's issues, through its forms: **Bug** or **Idea**. Search the open
issues first. For how to set up and use mimi-os, see the [wiki](https://mimi-agent-os.github.io/wiki/).

Security problems go through private reporting: see [SECURITY.md](https://github.com/Mimi-agent-os/.github/blob/main/SECURITY.md).

## Pull requests

Open an issue first; the pull request follows once the change is agreed there.

A pull request:

- links the agreed issue
- is small and focused on one change
- is in English: code, comments, docs and commit messages
- passes the repo's CI, which runs the checks its README lists: `pnpm check` and `pnpm test` in a package
- keeps to the existing runtime dependencies, unless the issue agreed to a new one
